# Limites d'interprétation

- complétion : indique une fin de flux observée, pas une orientation correcte ;
- reprise : indique un retour technique, pas une progression personnelle ;
- action créée : intention enregistrée, pas action réalisée ;
- action réalisée : déclaration ou preuve selon le contrat, pas effet causal ;
- blocage : signal utile pour adaptation ou soutien, pas diagnostic ;
- réorientation : correction possible, ni échec ni succès automatique ;
- demande humaine : besoin exprimé, pas qualité de la réponse reçue.

Toute communication doit préciser période, cohorte, consentement, taille,
manquants, source, version et limites. Les termes « efficacité », « réussite »,
« validation scientifique » ou « impact » exigent une preuve proportionnée.
