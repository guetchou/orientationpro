# Labels de triage

| Rôle canonique | Label GitHub | Signification |
|---|---|---|
| `needs-triage` | `needs-triage` | Évaluation par un mainteneur requise |
| `needs-info` | `needs-info` | Informations du demandeur requises |
| `ready-for-agent` | `ready-for-agent` | Spécification suffisante pour un agent autonome |
| `ready-for-human` | `ready-for-human` | Intervention humaine requise |
| `wontfix` | `wontfix` | Travail non retenu |

Les skills utilisent le label GitHub correspondant à chaque rôle canonique.
