# Documents de domaine

Le dépôt utilise actuellement un contexte unique.

## Lecture avant exploration

- Lire `CONTEXT.md` à la racine lorsqu'il existe.
- Lire les ADR pertinents dans `docs/adr/` lorsqu'ils existent.
- Employer le vocabulaire défini par `CONTEXT.md` dans les issues, tests et propositions d'architecture.
- Signaler explicitement toute proposition contradictoire avec un ADR existant.

Le passage à plusieurs contextes sera décidé lors de la création effective du monorepo. Il devra alors introduire `CONTEXT-MAP.md` et référencer chaque contexte applicatif.
